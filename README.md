
# Mohammed's Portfolio

## 🌟 Project Overview
This is a personal portfolio website showcasing my professional projects, skills, and experience.

## 🚀 Technologies Used
- React
- TypeScript
- Tailwind CSS
- Vite

## 🔧 Setup and Installation
1. Clone the repository
```bash
git clone https://github.com/yourusername/mohammed-portfolio.git
```

2. Install dependencies
```bash
npm install
```

3. Run the development server
```bash
npm run dev
```

## 📂 Project Structure
- `src/`: Source code directory
- `components/`: Reusable React components
- `pages/`: Individual page components
- `assets/`: Static assets like images

## 🌈 Features
- Responsive design
- Project showcase
- Personal information
- Contact section
